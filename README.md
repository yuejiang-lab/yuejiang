# 粤匠 · 广东非遗主题劳动备课平台

面向**中小学兼职劳动教师**的非遗主题劳动课在线备课网站。依据《义务教育劳动课程标准（2022 年版）》，把一节 40 分钟非遗劳动课从「选题」到「出稿」串成 10 个步骤：打开网页就能备课，无需注册；平台匿名统计使用行为，用于决定后续优先补充哪些主题与资源。

## 本地运行

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1 -Port 8080
# 或双击 启动服务器.bat
```

打开 <http://localhost:8080/>。也可以直接双击 `index.html`（`file://` 下全部功能可用）。

## 数据收集与隐私

- **不采集**：教师填写的任何备课内容（学情、目标、流程、任务单、量规、取证结论、反思）。这些内容只存在使用者本机 `localStorage`。
- **仅采集匿名行为**：页面浏览、选题编号、各步骤到达、导出类型与次数、取证进度，以及一个随机匿名编号。
- **知情同意**：首次访问底部出现提示条，可选择「同意并继续」或「仅本地使用」；未选择前只在本机缓冲、不上报；选择「仅本地使用」后不再上报。
- **完全关闭**：`assets/js/config.js` 中 `cloudEnabled: false` 即彻底停用上报，其余功能不受影响。

字段白名单在 `telemetry.js` 的 `FIELDS` 中，只有元数据可通过，从机制上排除备课文本被误带上行。

## 上线部署（腾讯云开发 CloudBase）

1. 开通云开发，创建环境（地域建议 `ap-guangzhou`），得到环境 ID。
2. **静态托管**：控制台 → 静态网站托管 → 上传本目录（或用 CloudBase CLI `tcb hosting deploy .`）。
3. **数据库**：新建集合 `usage_events`，安全规则设为「**仅创建者可读写**」（匿名登录用户写入自己的记录，管理端可读全部）。建议字段索引：`type`、`ts`。
4. **匿名登录**：控制台 → 登录授权 → 开启「匿名登录」。
5. **云函数**：上传 `cloudfunctions/getStats` 目录，函数名 `getStats`，用于首页聚合统计（避免在前端开放全表读取）。
6. **填配置**：编辑 `assets/js/config.js`

```js
window.YJ_CONFIG = {
  cloudEnabled: true,
  envId: '你的环境ID',
  region: 'ap-guangzhou',
  collection: 'usage_events',
  statsFunction: 'getStats',
  ...
};
```

未填 `envId` 时，网站自动降级为纯本地模式：备课功能完整可用，首页统计卡自动隐藏。

## 免费拿到一个网址的三种方式

本平台是纯静态站点（无后端、无构建产物），因此**任何静态托管都能免费运行**。三者按推荐顺序：

| 方案 | 费用 | 国内访问 | 匿名统计 | 适合场景 |
| --- | --- | --- | --- | --- |
| **① 腾讯云开发 CloudBase 静态托管** | 有免费额度（以控制台显示为准） | 快 | ✅ 已内置 | 面向广东教师日常使用（推荐） |
| ② GitHub Pages | 完全免费 | 较慢且不稳定 | ❌ 自动隐藏 | 开源分享、个人试用 |
| ③ 校内服务器 / 局域网 | 零成本 | 最快（内网） | ❌ 自动隐藏 | 学校内部、不对外公开 |

### ① CloudBase（推荐，约 10 分钟）

1. 打开腾讯云开发控制台，新建环境（按量计费即可，静态托管有免费额度）。
2. 进入「静态网站托管」→「文件管理」，把整个项目目录**原样上传**（`index.html` 必须在根目录）。
3. 开启「默认域名」，控制台会分配一个免费网址，打开即可访问，无需备案。
4. 想启用匿名统计，再按上一节的 3—6 步做（建集合、开匿名登录、传云函数、填 `envId`），重新上传 `assets/js/config.js` 生效。
5. 需要自己的域名：在「域名管理」绑定；**国内节点绑定自定义域名需要 ICP 备案**。

> 上传后如果首页统计卡显示不出来，说明 `envId` 还没填，属正常降级，不影响备课。

### ② GitHub Pages（完全免费、永久、无需实名）

**A. 先生成"发布版"文件夹**

双击 `生成发布版.bat`（或手动建目录），得到 `dist/`，里面只有网站本体：

```
dist/
  index.html  app.html  privacy.html  README.md
  .nojekyll
  assets/css/...   assets/js/...
```

`.nojekyll` 是空文件，用来跳过 GitHub 的 Jekyll 构建（不加也能跑，加了更稳）。
本地开发用的 `.bat`、`.ps1`、`serve.ps1`、PPT 等**都不进发布包**。

**B. 建仓库并上传**

1. 注册 GitHub（免费）→ 右上角 + → **New repository**
2. Repository name 例如 `yuejiang` → 选 **Public**（免费账户建 Public 才能用 Pages）→ 勾选 Add a README 可跳过 → Create
3. 进入仓库 → **Add file → Upload files** → 把 `dist` **里面的**文件和 `assets` 文件夹一起拖进去（注意是 dist 的内容，不是 dist 文件夹本身）
4. 底部点 **Commit changes**

> 网页上传不支持空文件夹，但 `assets` 下都有文件，直接拖 `assets` 整个文件夹即可。

**C. 打开 Pages**

5. 仓库 **Settings → Pages** → Source 选 `Deploy from a branch` → Branch 选 `main`、目录选 `/ (root)` → Save
6. 等 1–2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/` 即为公开网址
7. 统计功能不可用（首页统计卡自动隐藏），其余功能完整；备课内容仍在各人本机，不涉及隐私

**D. 以后更新网站**

改完本地文件 → 双击 `生成发布版.bat` → 回到仓库页面，把改动过的文件再上传一次（或删旧传新）→ 一分钟后生效。

**E. 使用反馈（替代收费的自动统计，零成本）**

1. 到腾讯问卷 / 金山表单等免费工具做一份问卷（问题示例："您备的是哪个主题？""卡在第几步？""希望补充什么？"），拿到公开链接
2. 编辑 `assets/js/config.js`，把链接填进去：

```js
feedbackUrl: 'https://wj.qq.com/s2/你的问卷地址',
```

3. 重新生成发布版并上传 `config.js`
4. 效果：首页「如何参与」出现第肆张卡片、备课页左侧出现「💬 使用反馈」按钮；**留空时这些入口会自动隐藏**，不会显示死链接

### ③ 校内服务器 / 局域网

- **Windows IIS / Nginx**：把站点根目录指向本项目目录，默认首页设为 `index.html`。
- **临时演示**：在一台常开的电脑上双击 `启动服务器.bat`，同一局域网内用 `http://<该机IP>:8080/` 访问。
- **最简单的分发**：把整个目录打包发给老师，双击 `index.html` 即可使用，不依赖任何服务器。

> 无论哪种方式，`index.html`、`app.html`、`privacy.html`、`assets/` 必须保持同一目录结构，不要只传单个 HTML 文件。

## 使用须知

- 备课内容自动保存在本机浏览器，换设备请用侧边栏「备份备课（.json）」导出后「恢复备份」。
- 平台只输出高置信内容：名录级别、传承人、价格、史实、版权、安全参数一律不代填，只给核实路径，由教师在第⑨步核实后回写。
- 未核实的条目在导出文档中保留 **【待核实】** 标记，补齐后才能标记为「合规可用」。
